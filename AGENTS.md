# aws-afc

Team fork of [aws-samples/sample-ai-possibilities](https://github.com/aws-samples/sample-ai-possibilities), used for the AWS Agentic Football Cup.

## Agentic Football workshop

For any detail about the Agentic Football workshop (game rules, commands, game state, timing, sample teams, Player Portal, deploy steps, Phase 3 upgrades, cleanup), read [docs/agentic-football-workshop-reference.md](docs/agentic-football-workshop-reference.md) first.

Football code lives in:

- `agentic-football-sample-agents/` — sample teams and the shared `lib/`
- `agentic-football-coach/` — the workshop's reference content
- `agentic-football-sample-agents/ai-team-kak1/` — our team (`README.md` there)
- `agentic-football-sample-agents/simulation/` — local match simulator; how to run it: `SIMULATION.md`

The rest of the repo is unrelated upstream samples.
